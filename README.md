# 수담기원

[바둑 대국실 열기](https://leejuhan-1214.github.io/baduk-online/)

모든 새 대국은 19줄 바둑판에서 시작합니다. **친구 대국**에서 방을 만든 뒤 초대 링크나 방 코드를 친구에게 보내세요. 처음에는 흑이 선공하고, 두 사람이 재대국에 동의하면 돌 색이 바뀝니다. 온라인 계정은 같은 브라우저 프로필에서 복구됩니다.

**봇 대국**은 쉬움·보통·어려움 세 단계이며 전적과 가상 코인을 기록합니다. **연습 대국**은 기기에서 바로 시작할 수 있습니다.

## 규칙과 정산

활로가 없는 상대 돌을 따냅니다. 자살수와 과거 판 모양을 되풀이하는 착수는 금지됩니다. 연속 두 번 쉬면 계가를 시작합니다. 죽었다고 보는 무리를 눌러 표시하거나 다시 눌러 취소하세요. 집과 사활에 이견이 있으면 대국을 재개할 수 있습니다.

새 대국은 살아 있는 돌로 둘러싼 빈집, 대국 중 따낸 상대 돌, 계가 때 양측이 사석으로 인정한 상대 돌을 합산합니다. 백은 덤 6.5집을 받습니다. 사석을 들어낸 자리가 집이면 그 빈집과 포로 점수가 각각 생깁니다. 공배와 빅의 집은 제외합니다. 계가 화면에서 양쪽이 같은 표시로 동의하면 결과와 코인이 확정됩니다. 업데이트 전 시작한 온라인 대국에는 당시의 면적 계가가 적용됩니다. [한국기원 바둑규칙](https://www.baduk.or.kr/story/badukRule.asp)

빈집·빅 판정에는 David J. Wu의 MIT 라이선스 라이브러리를 사용합니다. [GoScorer](https://github.com/lightvector/goscorer/tree/0ac5f59962a9e40f39f4667645335ba5068acf86)

친구 대국은 승리한 집 차이에 10코인을 곱합니다. 6.5집 승리는 65코인이고 기권은 10코인입니다. 친구 대국에서 잔액을 넘는 패배액은 음수 잔액으로 기록합니다. 봇 승리는 쉬움·보통·어려움 순으로 5·10·20코인을 지급하고, 패배는 10·10·20코인 중 보유한 코인까지만 차감합니다. 연습 대국에는 정산이 없습니다.

## 실행

Node.js 24에서 `npm install`, `npm test`, `npm run dev`를 실행합니다. 로컬 대국실은 <http://127.0.0.1:4189/>에 열립니다. GitHub Pages는 `main` 브랜치의 `docs/`를 게시합니다. `shared/go.mjs`와 브라우저 연습용 `docs/go.mjs`는 같은 규칙 모듈입니다.

온라인 서버는 `server/worker.mjs`에서 WebSocket 연결, 서버 측 착수 검증, 상태 복구, 중복 요청 방지를 처리합니다. D1의 대국 상태·전적·정산은 한 트랜잭션에 기록합니다. 배포할 때 `drizzle/`의 스키마를 적용하고 `DB` 바인딩을 연결하세요. `npm run build`는 Worker 배포 파일을 생성합니다. 게임 화면은 `docs/config.mjs`에 설정한 서버에 연결합니다.

## 두 브라우저 검증

Playwright와 Chromium을 설치한 환경에서 `node scripts/browser-smoke.mjs https://leejuhan-1214.github.io/baduk-online/`을 실행하면 독립된 두 계정으로 방 입장, 착수, 재접속, 계가, 정산 중복 방지, 재대국을 확인합니다.
